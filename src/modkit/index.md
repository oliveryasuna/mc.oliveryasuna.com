# Modkit

**One Gradle DSL for building Minecraft mods on both Fabric and NeoForge, from a single codebase.**

You describe your mod once in a `modkit { }` block. Modkit wraps the build tools the ecosystem already relies on, [Fabric Loom](https://fabricmc.net/), [NeoForged ModDevGradle](https://github.com/neoforged/ModDevGradle), and [Stonecutter](https://stonecutter.kikugie.dev/), and drives them for whatever loader and Minecraft version you're targeting. That way you don't have to wire each tool up by hand, and differently for every loader.
